# 本地素材 → 分镜样片 → 确认与下载

本次新增的可运行流程：

```text
已有分镜
→ 上传本地图片 / 配音
→ 逐镜头绑定素材并检查时长
→ 创建持久化渲染任务，锁定输入
→ 独立 FFmpeg Worker 合成 MP4
→ 视频与字幕预览
→ 人工确认 / 退回修改
→ 下载 MP4、SRT 与制作清单
```

这是静态图片、已有音频的分镜样片流程，三个内容方向共用。没有调用生成模型，也没有启用漫剧、沙雕角色动画或真人剧的完整生产引擎。不会生成角色表演、口型、视频动作或 TTS 配音；不宣称已经实现自动出片。

## 启动

安装 FFmpeg 与 ffprobe，确认 `ffmpeg -version`、`ffprobe -version` 可运行。FFmpeg 需要 libx264 与 AAC 编码器。可在根 `.env` 使用 `STUDIO_FFMPEG_PATH`、`STUDIO_FFPROBE_PATH` 指定可执行文件路径。

在项目根目录运行：

```bash
npm run setup:local
npm run dev:local
```

统一启动先迁移数据库，再运行 API、Next.js、魔因与独立渲染 Worker；无需 Docker、Temporal、GPU 或模型 Key。单独启动渲染 Worker：`npm run dev:render`。如果只启动 API 与前端，任务会留在队列中，不伪造完成状态。

FFmpeg 缺失或编码器不可用时，界面显示安装提示，拒绝上传/渲染，文本工作台仍可使用。实际运行验证在 Linux 云环境完成，Windows/macOS 本机尚未实测。

## 素材与镜头

项目页点击「素材与样片」。支持 PNG、JPEG、WebP 图片和 WAV、MP3 配音；原始上传文件最多 8 MB。图片检查内容格式、尺寸和实际解码，边长最多 8192、总像素最多 2500 万；损坏文件不进入素材库。

配音解码为 48 kHz、双声道 PCM WAV 保存，从实际采样确认时长，最多 120 秒。处理后的 WAV 体积可能大于上传文件；保留原始上传摘要、处理后文件摘要、原文件名及来源备注，不保留原始 MP3 字节副本。图片保留原文件字节。

每个镜头需要一张图片，可选择一段配音，未绑定配音时使用静音。短配音在镜头余下部分补静音；长于镜头的配音会在渲染预检中拒绝，要求延长镜头或更换配音，不会自动截短。页面可直接打开原有分镜编辑弹窗调整时长与对白。

素材绑定使用 revision 并发检查；拒绝把其他项目的素材误绑到当前项目，图片与音频类型也需匹配。魔因另存项目副本时，会复制已绑定素材的项目级元数据和绑定关系，文件作为不可变对象复用；未绑定素材库、历史渲染任务和确认记录不复制。删除分镜后，其绑定不会带入新副本。

这仍是基本素材管理，没有角色/资产版本审批、远程对象存储或素材授权审计系统。来源备注供人工记录使用，不能代替授权确认。

## 渲染与输出

当前每份样片限制为 1–100 个镜头、总时长最多 300 秒，画幅为 1280×720 或 720×1280，24 fps。按场景编号、分镜编号排序，图片按比例完整放入画面并补边，不拉伸裁切。

任务创建时锁定分镜 ID、revision、时长、对白、素材 ID、绑定 revision、素材摘要及来源、项目方向、Profile 和管线版本。后续修改不会改变当前任务。任务状态为 queued/running/succeeded/failed，进度来自已完成镜头数；没有伪造生成进度。

独立 Worker 使用原子条件领取任务、定期心跳，避免多个 Worker 重复执行。单镜头编码进程最多 240 秒、整份编码预算最多 15 分钟，随后检查输出；默认单 Worker 串行处理，编码线程限制为 2，并限制时长和输出文件大小。失败不提供部分样片，保留输入素材。运行中断后显式失败，不无限自动重试；排队任务在重新启动后仍可处理。超过 45 秒无心跳的在途任务会标记失败，并清理相应临时产物，用户可重新提交新任务。

FFmpeg 通过参数数组调用，文件名由程序生成，素材仅从受控本地目录读取，不提供任意 URL 代理。输出检查 H.264/AAC、画幅和总时长，合并时规范化音轨，避免短镜头的 AAC 填充累计改变时间轴。

生成四份文件：

- `video.mp4`：H.264 + AAC 样片，可在浏览器播放和下载。
- `subtitles.srt`：剪辑软件/播放器使用的字幕。
- `subtitles.vtt`：浏览器预览字幕。
- `manifest.json`：确切输入、素材摘要、实际 FFmpeg 版本、管线标识、输出摘要等制作清单，明确 `ai_generation_used=false`。

字幕来自分镜对白，按整镜头区间排列，不是 ASR 识别或逐字强制对齐；字幕作为独立文件，不烧录进视频。下载的 MP4 和 SRT 使用相同文件名主干，方便播放器配套读取。

相同请求标识的渲染重试返回原任务；普通重复点击会复用当前输入对应的请求。失败后或希望基于最新输入重新制作，可点击「重新提交新任务」。新任务不会继承旧样片的确认结论。

## 人工确认

样片完成后可填写备注，选择「确认这份样片」或「退回修改」。退回要求原因。每次操作新增不可变确认记录，并更新该任务的当前确认状态；重新打开仍可查看。只针对确切样片，不代表完成多人审核权限或完整 Review Center。

下载允许用于待确认样片的检查和返工，界面保留其确认状态，不把下载动作视为批准。

## 存储与接口

迁移 `0004_media` 添加素材、镜头绑定、渲染任务与确认记录；不会清空已有项目、故事和分镜。默认文件位于 `apps/api/.data/media`，可通过 `STUDIO_MEDIA_ROOT` 配置。**备份需同时包含数据库与媒体目录**；只复制 SQLite 无法恢复图片、配音和视频。

当前没有自动删除素材或历史样片，避免误删副本共享文件。中断上传与失败渲染的临时文件会清理；磁盘空间和长期保留策略仍需后续完善。

主要 API 前缀为 `/api/v1/media`：能力检查、项目素材上传/读取、分镜绑定、渲染任务创建/列表、产物读取与人工确认记录。创作快照版本 1 增加可选 `media` 字段，兼容旧文本快照和旧重试标识。

## 验证范围

SQLite 后端测试共 46 项、Chromium 浏览器测试共 10 项通过。实际调用 FFmpeg，覆盖三种方向的样片、双镜头音画/字幕、竖屏规格、输入修改后的历史输出隔离、多短镜头时间轴、渲染领取与中断恢复、损坏文件、超长配音、跨项目误绑、项目副本保留素材和失败回滚。浏览器检查真实播放、字幕加载、确认记录、实际下载后的 ffprobe 校验与窄屏布局。

测试图片与音频由程序生成，作为可重复的测试夹具，未冒充 AI 生成或用户正式内容。模型调用、AI 图片/视频、自动配音、完整剪辑时间线、程序角色动画、语义质检与费用预算均未实现或验证。FFmpeg 使用本机安装版本，分发相关二进制时应另行核对其许可证。
