# 故事与设定工作台

入口：项目页 →「故事与设定」。沿用现有 Next.js 工作台及浅色、青柠绿、淡紫 UI。没有更换 Vue 或将整套工作台替换为魔因。

当前可运行流程：

```text
小说 / 大纲 / 已有剧本原文
→ 保存原文与创作设定
→ 已有结构化剧本目录预览
→ 人工确认并另存项目副本
→ 魔因分镜编辑
→ 再次回存，保留原文、设定与分镜
```

这里的目录预览是确定性的格式解析，不进行 AI 推理。普通小说和自由大纲可以保存，自动拆解需要后续接入并验证真实模型；预览不会补写对白、画面或情节。未配置、未测试的模型能力继续显示尚未接入。

## 原文与设定

- 原文最多 100000 字符；可粘贴或导入 UTF-8 的 TXT / Markdown，文件不超过 500 KB。界面先读取至编辑区，点击保存后写数据库，不会自动覆盖已有目录。
- 设定包含故事大纲、世界观与风格、人物设定、连续性约束，各最多 10000 字符。
- 内容存于 SQLite（或已配置的 PostgreSQL）的 `story_drafts`，带 revision 与更新时间；并发新建和过期保存返回 409，不覆盖新草稿。页面保留被拒绝的本地编辑内容，用户可复制后再刷新。
- 这些是编辑草稿，尚无批准流程、历史版本、结构化剧情事实、角色知识或检索隔离；不能将其当作正式 Story Bible 系统已完成。
- 「保存并预览目录」先保存原文与设定，然后检查同一修订版本。修改输入后预览失效，需要重新预览。故事保存成功而格式预览失败时，原文仍保留。

## 结构化剧本格式

界面包含可展开的模板；空白原文可以一键填入模板，也可导入以下格式的文本文件：

```text
第1集：雨夜来信
简介：一封来自未来的信，改变了主人公的计划。
场景1：城市天台
地点：天台 · 夜
分镜1：信封特写
画面：雨落在旧信封上，镜头缓慢推近。
  这里是画面描述的下一行。
动作：主人公拿起信封。
对白：你终于来了。
  角色：缩进后含冒号的内容仍作为上一字段的续行。
时长：6
景别：CU
镜头运动：dolly-in
特殊手法：none
分镜2：抬头
画面：主人公望向远处的灯光。
时长：5
```

「第 N 集」「场景 N」「分镜 N」使用正整数编号，保留非连续编号。中文和英文冒号均可。集下可写简介，场景下可写地点；分镜字段为画面、动作、对白、时长、景别、镜头运动和特殊手法。多行文本续行必须缩进，避免把带冒号的对白误当字段。

未知行、错误层级、重复字段、重复同级编号、越界时长和超长文本会报错，不静默丢弃、截断、取整或重新编号。未写时长使用目录默认的 5 秒；最多 100 集、1000 场景、5000 分镜，受创作快照 4 MB 限制。

## 确认与回存

预览不创建剧集、场景或分镜记录。人工确认后通过已有原子导入接口创建项目副本，保留原项目。故事原文与设定随快照一起写入副本；后续从魔因再次另存时继续保留。

相同来源和文本的预览具有稳定 ID；同名、同内容重复确认使用相同幂等请求标识，返回已有副本。更改名称或文本会创建新的副本。目录创建与故事保存处于同一导入事务。

快照版本 1 增加可选 `story` 字段，兼容无故事字段的旧快照；原始魔因子模块保持固定版本与版权。共享主题和应用桥接均在主仓库维护。

## API 与迁移

- `GET /api/v1/story/projects/{id}`：读取草稿；没有草稿时 revision 为 0，不创建记录。
- `PUT /api/v1/story/projects/{id}`：提交完整字段及当前 revision；成功后版本加一。
- `POST /api/v1/story/projects/{id}/preview`：传入已保存的 revision，解析原文并返回创作快照。
- `0003_story` 迁移新增草稿表，统一启动会执行最新迁移。

## 实测范围

SQLite API、迁移和既有预检测试共 35 项；Chromium 浏览器测试共 8 项。新用例覆盖文件导入、设定与原文刷新后保留、目录预览不提前写入、确认副本、魔因继续编辑回存后保留设定，以及普通小说无法误报自动拆解、并发编辑冲突。主工作台类型检查、Lint、Next.js 构建与创作模块 Vite 构建通过。

本次没有配置服务商、调用付费模型、生成媒体或部署服务器。后续接入真实生成需要确定文本、图像、视频和配音服务商及准确模型标识；密钥应放在本机服务端配置中，不发送到浏览器或聊天。
